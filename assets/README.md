# Assets

External media for the Miles Dashboard. Referenced by filename — never base64, never inlined.

- `hero-batik.jpg` — SIA-batik hero treatment (navy + gold kawung motif, 1600×1000).
  Swap in your own photo of the same name to change the hero; the CSS layers a
  legibility wash over it, so a dark image works best.
- `batik-motif.svg` — kawung batik tile, used as a faint full-page texture.
- `logo.svg` — origami-crane wordmark in the header.

Keep any replacements optimised (JPG/WebP, < ~300 KB) for fast loads.
